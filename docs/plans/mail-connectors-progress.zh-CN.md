## 2026-11-22 租户接入（C4，T10）

分支 `feat/tenant-connect`，计划 [tenant-connect.plan.md](tenant-connect.plan.md)，只做 API 和契约。

### 2026-11-22 租户接入：第二轮审查修复（N1 到 N3）

- 默认采用、待确认（N1）：私人分配记录在员工离职、交接、清除副本、撤销租户后都保留，并记录隐私边界（离职时间，或员工在职时交接的时间，取较晚者）。此后为其他人（或作为共享）新建或恢复该地址的邮箱时，从边界开始同步：不向服务商要更早的邮件，入库时也丢弃边界之前收到的副本。员工离职后待交接的分配不能断开、清除（含保留期清理任务）或改派，只能交接或等员工回来。除最近一次的私人持有人外，其他人自行绑定该地址一律拒绝。

### 2026-11-22 租户接入：第三轮审查修复（N4 到 N6）
